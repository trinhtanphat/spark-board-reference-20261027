# SPARK / The Bare Board
An original, responsive visual re-creation inspired by the SPARK PCB / firmware dashboard visible within a user-provided screenshot.
## What is included
- Responsive HTML/CSS layout and editor pane, zero UI frameworks.
- Seeded procedural circuit-board artwork in Canvas (not a pasted screenshot).
- Oscilloscope waveform, diagnostic tiles, four interactive bay cards and demo telemetry.
- Static Node HTTP server, no dependencies. Numbers are simulated.
## Run
node server.js
Then open http://localhost:8788.
## Environment
Built in an isolated folder on WIN11-181. No existing services, tunnels, browser tabs or projects need to be modified.
